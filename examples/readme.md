This directory holds example programs that I have written for you to look at either for inspiration or example.

In this directory you will find:
- [importing](./importing/) which is just a basic example of how you can make imports to code that you have written
or included in your own projects.
- [rock, paper, scissors](./rock_paper_scissors_example/) is my implementation for rock, paper, scissors. Code here 
is exemplary for what your code should look like after COMP271.
- [text editor](./text_editor/) is a similar clone to `ed`, a 1960's text editor.
